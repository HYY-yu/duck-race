# Duck Rush 0.2 · 水体与落差物理

## 与原项目的关系

Duck Rush 已于 2026-10-22 从 `packages/duck-rush` 提升到仓库根目录，成为主项目，保留原有 TypeScript、Vite、Three.js 依赖与锁文件。旧版 Duck Circuit 位于 `archive/duck-circuit`，其水体、赛道、比赛代码及原 `src/waterfall.ts` 的未提交修改随目录完整归档。

参考并适配旧版 `archive/duck-circuit/src/` 下 `water-material.ts`、`water-wave.ts`、`water-environment.ts`、`waterfall.ts` 中的水体方法。保留 Three.js Water2 双相法线混合来源说明和 MIT 许可，见 `public/licenses/three-water-MIT.txt`。没有新增大型依赖，也没有引入 three.quarks 或通用刚体引擎。

## 水体

- MeshPhysicalMaterial：透射、IOR=1.333、水深衰减、粗糙度随泡沫变化。
- 两套程序化法线、双相循环混合，避免流动 UV 长时间剪切拉伸。
- 静态山谷/天空 cubemap，经 PMREM 过滤作为反射环境；不是实时平面镜面或 SSR。
- CPU 浮力与 GPU 顶点使用同一组多尺度波浪，并在岸边渐隐。
- 河床有真实深度和流动焦散纹理；岸边泡沫、急流气泡与落水区连续衔接。
- 两段 4.8 m / 3.5 m 高度落差。河面在瀑布间隙断开，独立抛物线水帘有厚薄绳状纹理、破碎边缘、入水驻波、泡沫拖尾、飞沫与薄雾。
- 粒子固定容量：瀑布持续喷雾 360，鸭子事件飞溅 720，扩散涟漪 24。重开清空旧事件；没有每次碰撞创建无限对象。

## 运动与碰撞

仿真保持固定 60 Hz，状态位于 `simulation.ts` / `dynamics.ts`，渲染只消费状态与事件。

鸭子有独立世界高度、垂直速度、俯仰/侧倾/偏航及角速度。越过唇口时离水，保留水平动量并接受重力；空中不再被水流直接加速。接触下游水面时记录入水速度、激发阻尼浮力与转动、减少水平速度，发出一次 landing 事件。飞溅范围和水滴速度随入水速度变化。

摆锤、四叶水平水车、升降杆使用与可视动画一致的位置和相位。接触按相对速度、碰撞法线传递线性及角向冲量，可以短暂倒退、侧推和旋转。鸭间有斥力与接触冲量；岸边反弹。水车区扩大通行宽度并降低转速，保留真实可通行路径，没有卡住后的补速、传送或预设胜者。

这是面向河道竞速的约束运动/碰撞代理，并非完整六自由度刚体、连续流体求解或精确网格接触。水帘轨迹为美术控制的参数曲线，鸭子下落则由重力积分独立计算。

## 可观测性与验收入口

- Info：水环境初始化、比赛开始/结束、每只鸭子的完赛/落水次数/碰撞次数。
- Debug：takeoff / landing / contact 事件及冲量、入水速度、时间。
- Warn/Error：存储、WebGL 上下文与渲染失败不隐藏。
- 只读 `window.__DUCK_RUSH__.physics` 含每只鸭子的高度、空中状态、姿态、落水数、碰撞数和入水速度。
- 开发模式可访问 `/?inspect=fall`、`/?inspect=landing`、`/?inspect=contact`。以 seed=42 跑真实仿真至对应事件再暂停，便于重复截图；生产构建不提供此入口。
- 预留统一 tracing / metrics 接入点，没有遥测外发。

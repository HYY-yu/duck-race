# 松风山谷 / Pinewood Valley

松风山谷（原长赛道）入口为 `/zh/?track=long` 或 `/en/?track=long`；不带 `track` 的语言主页默认加载雪岭激流，标准赛道已下线，旧 `?track=standard` 链接转到松风山谷并保留种子等参数。顶部赛道菜单在同一语言页切换赛道并保留其他查询参数；语言链接保留 `track` 与 `seed` 后刷新到另一语言页。页面内未完成名单与比赛状态不会跨刷新保留。

## 布局和道具

- 基础中心线约 196.526 米；松风山谷约 422.531 米，比例 2.15。水平路径和岛屿同步展开，水道宽度、鸭子和道具尺寸不放大。松风山谷水流在原模型基础上统一乘以 1.10（此前 1.25，本次下调约 12%），几何长度仍为 2.15 倍。
- 两座彩虹位于 s=53.75、311.75；跨河布置，云朵在河岸，所有允许泳道上至少有 3.3 米净空，允许带挂件的鸭子钻过。
- 滑梯水道位于 s=206.4–236.5，长 30.1 米。平滑重新分配 4 米高差，叠加原有坡度，入口/出口水面与实际浮力高度一致；蓝色滑槽、黄色护栏和支架沿真实曲线生成。滑梯范围移除原有河岸石块，鸭子速度由原有坡度/水流仿真决定。
- s=378.4 增加风车塔、岸边竖直水车和河内转桨；全部使用比赛时间旋转。河内转桨复用旋转障碍碰撞模型，暂停冻结、重开复位；岸边风车/竖直水车是表现层组件，不扩大河内碰撞范围。
- 与雪岭激流一致，所有泳道在倒计时结束时保持零速，由河道水流开始推动；不再给首弯内侧泳道额外初速度。准备、倒计时与暂停不移动，重开清零。
- 原有交通锥、四类机关和两处瀑布保留，沿长版路径重新布置。瀑布水平间隙仍为 3.2 米，保证既有离水/入水仿真兼容。
- 终点观众桥、地形、岸线、湖面、全景镜头范围随长版调整；树木继续应用河道净空和树冠间距筛选，并避开新道具。

## 状态和资源

每个页面加载一个不可变赛道配置。新历史记录和复制结果使用 `long`（松风山谷）或 `mountain`（雪岭激流）标记；历史 `standard` 记录保留并显示已下线标签；无该字段的旧记录保持兼容，不推断其赛道。更换赛道可能改变相同种子的结果，记录种子不能代替赛道版本。

道具采用轻量程序化网格，复用现有材质/Three.js，无新增下载模型、付费生成或第三方依赖。两条在用赛道的地形采用 1.6 米网格间距控制面数。

## 验证

- 独立长版进程验证长度比例、河口湖面连续、滑梯高差、河面无地形遮挡、全泳道彩虹净空，以及道具场景结构。
- 2、6、12 只鸭子，各 3 个种子，共 9 场固定步长真实仿真全部完成；流速倍率调整为 1.10 后用时约 22.9–23.55 秒（此前约 19.2–19.7 秒），全部经过滑梯与两次瀑布，且验证了新转桨实际产生接触事件。
- 自动化覆盖零速起步、倒计时/暂停冻结、重开清零、两段腾空/落水及完整完赛。浏览器验证全景、穿彩虹、滑梯、风车水车和雪山同款跟随镜头。
- 开发模式 `inspect=rainbow|slide|windmill` 运行真实固定步长仿真到对应区段，暂停后提供近景；生产构建不启用该检查入口。
- 尚未做移动真机 GPU 或长时间性能验收；构建仍有 Three.js 主分块体积提示。

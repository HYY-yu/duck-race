# 长赛道 / Long course

在标准版旁新增独立长赛道版，入口为 `/?track=long`；默认 `/` 和 `/?track=standard` 继续加载标准版。右上角双语链接在新标签页打开另一版，保留当前页面的名单和比赛状态；不同页面的配置独立。

## 布局和道具

- 标准版中心线约 196.526 米；长版约 422.531 米，比例 2.15。水平路径和岛屿同步展开，水道宽度、鸭子和道具尺寸不放大。长版水流在原模型基础上统一乘以 1.25，几何长度仍为 2.15 倍。
- 两座彩虹位于 s=53.75、311.75；跨河布置，云朵在河岸，所有允许泳道上至少有 3.3 米净空，允许带挂件的鸭子钻过。
- 滑梯水道位于 s=206.4–236.5，长 30.1 米。平滑重新分配 4 米高差，叠加原有坡度，入口/出口水面与实际浮力高度一致；蓝色滑槽、黄色护栏和支架沿真实曲线生成。滑梯范围移除原有河岸石块，鸭子速度由原有坡度/水流仿真决定。
- s=378.4 增加风车塔、岸边竖直水车和河内转桨；全部使用比赛时间旋转。河内转桨复用旋转障碍碰撞模型，暂停冻结、重开复位；岸边风车/竖直水车是表现层组件，不扩大河内碰撞范围。
- 起跑时以第一弯道判定内侧（当前为 lane=-1.6）：倒计时结束才给内侧泳道最多 1.2 米/秒初速度，中央和外侧为零，各排相同；准备、倒计时与暂停不提前移动，重开清零。该速度只施加一次，之后仍由水流和接触决定，不按姓名或名次补速。
- 原有交通锥、四类机关和两处瀑布保留，沿长版路径重新布置。瀑布水平间隙仍为 3.2 米，保证既有离水/入水仿真兼容。
- 终点观众桥、地形、岸线、湖面、全景镜头范围随长版调整；树木继续应用河道净空和树冠间距筛选，并避开新道具。

## 状态和资源

每个页面加载一个不可变赛道配置。新历史记录和复制结果包含 `standard` 或 `long` 标记；无该字段的旧记录保持兼容，不推断其赛道。更换赛道可能改变相同种子的结果，记录种子不能代替赛道版本。

道具采用轻量程序化网格，复用现有材质/Three.js，无新增下载模型、付费生成或第三方依赖。长版地形采用 1.6 米网格间距控制面数，原版仍使用 1 米间距。

## 验证

- 独立长版进程验证长度比例、河口湖面连续、滑梯高差、河面无地形遮挡、全泳道彩虹净空，以及道具场景结构。
- 2、6、12 只鸭子，各 3 个种子，共 9 场固定步长真实仿真全部完成；加速后用时约 95–107 秒（调整前约 123–139 秒），全部经过滑梯与两次瀑布，且验证了新转桨实际产生接触事件。
- 全套 49 项测试与类型检查/生产构建通过。额外覆盖内侧各排一次性起步速度、倒计时/暂停冻结及重开清零。浏览器验证全景、穿彩虹、滑梯、风车水车和跟随镜头。
- 开发模式 `inspect=rainbow|slide|windmill` 运行真实固定步长仿真到对应区段，暂停后提供近景；生产构建不启用该检查入口。
- 尚未做移动真机 GPU 或长时间性能验收；构建仍有 Three.js 主分块体积提示。

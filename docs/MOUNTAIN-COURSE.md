# 雪岭激流 / Snowpeak Rapids

默认地图吸收 `/Volumes/GW/codes/ZCodeProject/duck-race` 的种子山地河道、非对称河岸、横向拨水、自然腾空和脱困设计，沿用当前项目的模型、水材质、镜头和名单流程。不添加依赖。

## 使用

- 默认：`http://127.0.0.1:5183/zh/` 或 `/en/`（地图种子 42）。根路径是手动语言选择页。
- 复现/换地图：`?seed=917` 或 `?track=mountain&seed=917`。种子为 uint32，修改 URL 并刷新会同时生成河道、地形噪声、岩石和植被；页面生命周期内地图不可变。
- 旧地图：`?track=standard`、`?track=long`。
- 点击名单跟随鸭子，`A / D`、`← / →` 拨水。仅对比赛中、未腾空的跟随鸭子施加横向力，不改变纵向速度、动力或排名。失焦、页面隐藏、弹窗、全局镜头不接受拨水。
- 地图种子与抽签随机种子独立。记录包含 `course`、`trackSeed`、`controlled`；人工拨水会影响结果，界面、历史和复制文本标注人工操作。人工操作记录不支持仅凭种子重放。

## 地图与水流

`src/mountain-course.ts` 生成逐渐向外展开的盘山样条与切线连续出山段。`src/track.ts` 按水平弧长采样，构造下降高度、两道飞瀑、跌水潭、窄槽、沙洲分流和六组机械障碍；礁石/沙洲的渲染和碰撞共享 `blockers`。

带符号曲率决定左右半宽：内侧收窄、外侧加宽，总宽不变。水面网格、岸石、岸线碰撞、地形雕刻和水波的岸距共用半宽计算。水速按半河道有效宽度的幂函数近似连续方程，沙洲进一步压缩各支流有效宽度，因此窄侧更急；鼓风机提供局部环境气流。它是赛道坐标里的简化水动力，不是完整三维流体或刚体求解。

山体使用种子噪声高度场、河道雕刻、坡面松弛、草地/裸岩/雪线顶点色、雪顶岩群和低海拔森林，镜头碰撞与植被共用同一高度场。

## 腾空与保底

飞瀑坡度超过 `launchSlope` 时失去支撑，保留进入前的纵向与世界垂向速度，在重力下积分；落水时恢复浮力阻尼。飞行期间没有水流拖拽或拨水。飞瀑编号用于去重和落水统计，不提供向上弹射速度。

水中累计前进不足 0.8 单位达到 `stuckSeconds` 后，施加朝向空隙的侧向冲量，增加 `recoveries`，打印 Warn。不会直接改 `s`、纵向速度或冲线结果。该机制通过采样回归验证，不声称对所有 uint32 种子或任意调参都数学保证完赛。

## 手感调参（不新增设置界面）

编辑 `src/tuning.ts` 的 `FEEL`（通用阈值与脱困）与 `RAPIDS`（三条赛道共用的雪山手感）：

| 参数 | 作用 |
| --- | --- |
| `baseFlow` | 山地河道基础水流速度 |
| `waterDrag` | 水流拖拽/速度收敛 |
| `lateralDrag` | 横向阻尼 |
| `steerAcceleration` | 拨水力度 |
| `repulsion` | 鸭子之间斥力 |
| `gravity` | 飞行重力 |
| `launchSlope` | 腾空坡度阈值 |
| `bendNarrowing` | 内外岸不对称幅度 |
| `stuckSeconds` / `escapeImpulse` | 卡死检测时间/侧向脱困力度 |

赛道高度、宽度、飞瀑、机械障碍和自然阻挡位置在 `src/track.ts` 调整。改变手感或几何后需要重跑 `npm test` 和 `npm run build`；涉及画面时还需浏览器确认。

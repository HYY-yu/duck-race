参考图由内置 ImageGen 逐个生成。提示词：`assets/generated/remaining-v1/prompts.json`，阔叶树重做提示词：`tree-broadleaf-v2/prompt.txt`。使用 `wavespeed-ai/trellis-2/image-to-3d`，参数 resolution 512、texture_size 1024、target_face_count 10000、remove_background true。首批 seed 42，重试 seed 7；阔叶树 v2 使用新参考图与 seed 42。[供应商说明](https://wavespeed.ai/models/wavespeed-ai/trellis-2/image-to-3d)。

## 离线处理

`node scripts/prepare-generated-assets.mjs` 自动选用存在的 `-v2` 原件，输出 `public/models/`，不触发付费生成。

- 用现有 meshoptimizer 做带 UV 约束的减面；细薄结构或接缝过多时保留完整网格，避免强行达到目标面数。实际约 1,800–10,000 三角面，具体见 `web-manifest.json`。
- 对位置重合的 UV 分裂点计算一致法线，但不焊接 UV。大多数资产只修法线；鸭子保留已批准的 Taubin 平滑版，围巾轻度平滑。
- 零面积/相消邻域用来源法线或有限方向回退，记录 Warn 和 manifest，不静默输出零法线。
- 本批彩色贴图缩至 512px，移除金属/粗糙度贴图，改为非金属哑光材质；围巾移除不用的纹理。鸭子沿用原先 1024px 配色纹理。
- 不引入新依赖，保留所有原始模型。体积、面数、来源版本见 `assets/generated/remaining-v1/web-manifest.json`。

## 运行时

`src/generated-assets.ts` 使用 GLTFLoader 并行加载、缓存几何和纹理；鸭子按 `COLORS` 在本机生成共享身体配色，保留嘴和眼睛。挂件按编号循环：无、海盗帽、骑士头盔、眼镜、围巾。饰品不参与物理或随机分配。

`World.replaceGeneratedModels()` 加载后原位替换视觉对象。期间保留原模型；失败记录 Error/Warn 并保留对应 fallback。`window.__DUCK_RUSH__.generatedAssets` 提供 ready、loaded、failed、milliseconds。

两种树各一个 InstancedMesh；兔子、鸭子共享几何。飞鸟加入翼骨；观众按位置生成头/双臂蒙皮权重，复用原有注视、拍手、挥手、跳跃及暂停逻辑。这是轻量自动蒙皮，不是手工完整角色动画。遮挡检测沿用保守场景代理。

### 树木摆布修整

`src/tree-layout.ts` 对原有随机散点进行确定性筛选，不额外消耗场景随机数。按实际 GLB 的横向包围半径留间距：阔叶树 3.2、松树 2.2（再乘各自缩放），树冠之间至少留 0.65 间隔。河道、机关、起终点、泉眼、观众桥及兔子活动点留净空；陡坡、树根高度变化过大或坡面进入树冠的位置拒绝种植。树根按周围采样最低地面略微埋入，减少斜坡悬空。

生成树与临时几何树使用同一份筛选结果，镜头代理同步采用各树种的实际尺寸，避免删掉树后仍遗留原位置的树冠代理。保留正常山坡与随机疏密，未改竞赛物理。新增测试覆盖实际模型尺寸、树冠间距、场景净空、坡面与确定性。

### 胸前红领巾（2026-10-22）

`src/duck-scarf.ts` 用共享几何构造哑光红围领、胸前居中的短结及两片下垂布角，替代不完整的生成围巾装配；无新增依赖、付费调用或竞赛物理变化。按用户要求改为胸前红领巾样式，移除向侧后方外展的飘带；两片布角保持在胸前中线，避开左右翅膀。领结下移至胸口并向内收，与鸭嘴留出间隙；布角根据现有鸭子胸部采样轮廓弯曲，细分后再变形，避免大三角面切入圆润鸭胸。编号循环保持不变，围巾不再依赖原始 scarf GLB 加载成功。

装配验收页新增「围巾多视角 / Scarf views」，同时展示正面、侧面与背面。截图：`docs/screenshots/duck-neckerchief.png`。此前全量 53 项测试通过；此次构建与围巾专项 2 项测试通过，检查胸前布角范围、有限几何、共享资源和无原始围巾模型时的装配。已进行浏览器多视角静态检查，尚未作真实手机比赛视角验收。

# 2026-10-26 比赛流程验收

结论：本轮普通入口验收通过，未发现新的比赛状态残留。没有修改业务代码，也没有使用 `inspect` 参数、注入比赛状态、替换随机源或加速模拟。全部开始、暂停、继续、重开、切图和名单编辑都经界面操作。

生产构建来自当前工作区，核心流程基线为 `0897d80`。预览运行在独立的 `127.0.0.1:5190`，与日常 `5183` 的本机历史隔离。工作区原有 SEO 草稿未改动。覆盖中文/英文、桌面及约 391px 宽的窄屏布局；窄屏是桌面浏览器视口模拟，不代表手机真机触控、温升或耗电验收。

## 重点状态转换

| 验收项 | 结果 |
| --- | --- |
| 普通入口、刷新后的初始状态 | ready、time=0、全局镜头、编号0、无本轮抽签ID/结果/事件反馈/弹窗 |
| 倒计时暂停与继续 | 倒计时文本、鸭子位置冻结；继续仍使用原抽签ID，正常进入比赛 |
| 比赛中暂停与继续 | 计时、所有鸭子位置、已完成结果冻结；继续保留进度与原抽签ID |
| 部分鸭子完赛后暂停 | 12鸭一轮在2只完赛时暂停，已完赛与未完赛的鸭子一起冻结；继续后12/12完赛 |
| 暂停时打开/关闭帮助 | 不会意外恢复比赛 |
| 取消重新开始 | 原状态、进度和抽签ID保留；比赛中取消后继续比赛，原本暂停则仍暂停 |
| 确认重新开始（比赛中/倒计时/暂停/窄屏） | 清空本轮进度、结果、ID、反馈和完赛展示；鸭子回到起点，镜头立即全局复位 |

| 刷新（待开始/倒计时/比赛中/暂停/完赛） | 均恢复普通待开始；不继承暂停、计时、排名、抽签ID或结果弹窗 |
| 切换地图（待开始/倒计时/比赛中/暂停/完赛） | 新地图待开始，旧抽签ID/排名/声音不继承；地图种子保留 |
| 切换中英语言 | 赛道/地图种子保留，页面从普通待开始进入 |
| 自然完赛和自动结果弹窗 | 四轮全部完赛，完整排名有序、无重复；完赛后官方计时不变，正常经过湖面展示后自动弹出结果 |
| 关闭/重新打开结果、同名单再抽 | 结果完整；再抽回到干净待开始状态，保留名单；实际开始时生成新抽签ID |
| 历史记录 | 每场完赛只新增一次；重开、未完赛刷新/切图不写入；重开/刷新后已完成历史仍可查看 |
| 窄屏菜单和遮罩 | 菜单重开先打开确认框；实际确认后菜单、弹窗、遮罩、body滚动锁均清理，场景不残留inert状态 |
| 名单校验和取消 | 1人、重名、13人均禁止保存；取消编辑不覆盖原名单 |
| URL和最终清理 | 全部60个状态快照的URL均无inspect；额外测试页已关闭，临时预览服务已停止，原Chrome保留普通入口 |
| 控制台与资源 | 浏览器error日志0条；最终全部场景资源加载完成 |

刷新、切图和语言切换是整页重载，当前行为是恢复默认6人名单；同页面内重新开始/同名单再抽保留已配置名单及颜色。已完成历史按设计保留，属于持久记录，不是仍在运行的比赛状态。

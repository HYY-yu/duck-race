# 东南亚 Three.js 网页小游戏机会筛选

研究日期：2026-10-21。结论：先做菲律宾英语的 3D Duck Race Name Picker（鸭子竞速点名器），用 3–5 天交付小实验。备选为泰国抓娃娃、印尼停车。尚未证明任何一个方向是 SEO 蓝海或能靠广告盈利。

## 研究依据与范围

读取 OpportunityRadar 的“小游戏雷达”（ID 2），现有 152 个关键词及研究 2、4、5、6；其市场均为美国英语。保留当前配置，使用项目已有 OpenSEO 连接的 Default workspace 按国家补充查询，不把美国数字当成东南亚需求。

本轮 6 国、145 个关键词×市场组合，9 次指标查询返回 112 条记录；另查 8 个移动端 SERP（depth 10，包含 App/AIO/视频等元素），并核对公开竞品页面。手动种子抽样不是穷尽发现；缺失不等于零需求，KD=0 不等于没有竞争。英语种子在部分国家使用本地语言配置查询，不能当作该国所有语言总需求。

原始响应与每次国家、语言、关键词保存在 [证据包](2026-10-21-southeast-asia-threejs-evidence.json)。本轮补充查询由 OpenSEO 执行，未写入小游戏雷达原生 research/费用账本；工具未返回 USD 或 creditsCharged，实际开销待 OpenSEO 自身记录核对，不能写成免费。未新建雷达、未调整预算或定时任务。

## 为什么选菲律宾 Duck Race

### 具体的工具词比泛游戏词更可用

|---|---:|---:|---:|

| 印尼 / id | 18,100 | 480 | 320 |
| 越南 / vi | 49,500 | 未返回 | 480 |

| 马来西亚 / en | 4,400 | 390 | 未查 |

菲律宾 name picker 近三个月（2026-07→09）为 2,900→1,600→2,900；online 为 320→260→720，有波动。大词 duck race 混合了 App、教程、真实鸭子比赛、鸭子滑水游戏，不能用 74,000 计算可获流量。越南 đua vịt（33,100）和印尼 balap bebek（1,600）也有相同意图问题，不能与英语词累加。

菲律宾英语精确词 SERP 出现 duckrace-game.com、online-stopwatch.com 和 GitHub Pages 工具站，说明这个查询确实能由网页工具承接。一个 GitHub Pages 站进入结果只是竞争结构线索，不证明新域名易排名。

菲律宾教育部门的一份活动议程列有“4 SDOs (thru Duck Race)”（[原始 PDF](https://depeddigoscity.org/storage/wp-content/uploads/2024/11/DM_SGOD_2024_779.pdf)）。越南 [SUN English](https://sunenglish.edu.vn/tro-choi-tieng-anh/game-dua-vit-cong-cu-dua-vit-online-goi-ten-hoc-sinh-ngau-nhien/) 实际提供课堂鸭子点名器。这些是场景证据，不代表使用人数、付费意愿或市场份额。

先菲律宾、再马来西亚，是为了首版中英文就能服务英语用户。越南和印尼的本地词可用于后续验证；若扩展当地语言页面，需要另定语言范围及母语校对，不能仅用关键词替换制造落地页。

### 竞争已经很完整

- [Online Stopwatch](https://www.online-stopwatch.com/duck-race/)：免费 2–100 鸭，付费支持 1,000 鸭，提供全屏。
- [Duckrace-game.com](https://www.duckrace-game.com/)：名单、比赛时长、结果排名和保存名单；其用户量及场次是官网自述，未独立验证。
- [Random Duck Race](https://randomduckrace.com/)：公开页面宣称 3D 河道、1,000 鸭、100+ 皮肤、16 种语言、CSV/Excel、分组、房间与分享。
- [GitHub Pages 名字选择器](https://duck-race-name-picker.github.io/)：公开页面宣称免费 1,000 名字和课堂/直播模式。

因此，“3D + 输入名字 + 分享 + 多语言”不是独有卖点。能验证的切入是假设：对只需点一个学生的用户，加载更轻、步骤更少、姓名更清楚，是否足以让他换工具。竞品功能基于公开页面，未做手机加载时间、真实公平性或跨设备性能基准；不能预先声称比其快。

### 建议首版

一个独立网页即可：
1. 2–60 个名字，直接粘贴，去除空行，重复姓名提示。
2. 10/20/30 秒，开始、暂停、再来一次；中英文。
3. 一只低多边形 GLB 鸭模型复用，换颜色，固定清晰镜头，名单与比赛区域兼容手机和投影。
4. 结果大字显示；可移除本轮选中者，继续下一轮。
5. 名单保存在本地，主动操作才分享；默认分享不包含姓名。
6. 首版为单机随机点名的 3D 动画展示，不做实时房间、聊天、账号或视频导出。

把随机选择与视觉演出分开：均匀抽样产生结果，再播放到终点的动画；清楚说明规则，不宣称物理模拟决定公平性。这样不必实现复杂浮力、碰撞和联网同步。公平抽样与剔除后不重复要有单元测试。

可验收的性能目标（待实测）：首屏压缩传输预算 2 MB 内；低档 Android 开赛可达 30 FPS；资源失败/WebGL 不可用时保留简单名单选择与错误提示。技术选择只需 TypeScript + Three.js、静态托管与本地存储。

事件记录：page_view、asset_load_success/failure、race_start、race_complete、pick_again、share_click、WebGL/context_lost；不记录真实姓名。Debug 记录加载/状态节点，Info 记录关键完成事件，Warn 记录可恢复降级，Error 上报未恢复故障。指标关注加载到首次开赛、完赛率和错误率。

### 流量入口与验证

主页面承接 duck race name picker，同一真实产品覆盖 duck race online、duck race with names 的自然相关表达。课堂模式只有提供真实投影布局等差异后才单独做页面，避免同功能批量造词页。

首批展示素材：粘贴 30 个名字→10 秒开赛→显示被选中者的短演示。渠道假设为教师、培训、会议主持场景；是否允许发帖、能否带来使用需要逐一验证，本轮未发布帖子或联系他人。

先找 10 名符合场景的使用者，与现有工具完成同一任务。自定门槛：
- 至少 7 人无需指导完成首轮；
- 至少 3 人在 7 天内再次使用，或主动发给他人；
- 记录是否愿意替换原工具及原因。

这些是实验门槛，不是行业标准。SEO 验证要给索引与搜索表现时间：检查索引与真实查询词，再看非品牌曝光、点击和开赛。7 天无搜索流量不能判定失败；若 4–6 周仍无目标查询曝光，应检查索引、意图和竞争，不能盲目堆皮肤。

用实际流量与真实广告收入再评估变现。CPC 不是发布商 RPM；现阶段没有该站广告填充率、RPM、回访与获客成本，不能预测回本。不要靠在每次课堂点名前插广告的假设设计首版。

## 备选方向的边界

### 虚拟抓娃娃

适合用模型形成收藏感：6 个原创玩具、固定机器、可控抓取规则、每日摆放。泰语词 SERP 同时出现 Google Play、Y8、Kapook 和实体机器购物结果，KD=0 仍有竞争。[CLAW](https://clawthegame.com/) 已公开展示 3D、15 关、收藏、手机操作和片段录制；不能将这些当作独有优势。

首版若采用距离/姿态判断抓取，应清楚展示规则，不用重型关节物理冒充“真实模拟”。工期风险大于鸭子工具。泰国/越南本地词承接还需要当地语言内容，因此在当前中英文范围下优先级下降。

### 停车

印尼 game parkir mobil 在 2026-07→09 为 210→320→590，但更明确的 game parkir mobil online 只有 30/月。该词移动 SERP 已有 Poki 的 Car Parking Jam、CrazyGames 的 3D Underground Car Parking 与本地门户。做印尼车辆换皮并不自动获得本地流量。

若做，先选“自由转向停车”或“网格出库解谜”其中一种；本轮指标不能混同证明两种玩法需求。固定镜头、10 关、一个可辨识车辆模型，优先打磨手机操作，不做城市开放世界。

### 街头小吃

模型与食物反馈匹配，但需要更多动效、订单、教程及文化细节。[a Bit SaiGon](https://abitsaigon.com/) 已提供浏览器内越南街头餐饮协作玩法，[Own Games](https://own-games.com/games/Akang-Tahu-Bulat?hl=en) 与其网页产品也覆盖印尼食品题材。本地饮食不是竞争空白；大类词热度不能证明新单菜品站的流量。

## 本次排除或降级

- 美国弹珠结论：六国 marble race simulator 仅 10–50/月，marble race online 10–50/月；本次抽样内明显弱于鸭子相关词，不优先沿用美国定位。
- Jeepney Simulator：菲律宾 1,300/月、KD 6，但移动 SERP 第一为 Steam 的现有同名游戏，知识面板及续作结果明确；另有网页版 Pinoy Jeepney Simulator。该词主要有品牌意图，不能称为低难度通用题材蓝海。
- 印尼 Basuri：telolet basuri 1,600/月，但 2026-07→09 为 1,300→1,000→880；game basuri 90/月且最近三月 50→40→40。包含音乐、喇叭、模组与 App 搜索，3D 巴士不是简单流量解法。
- Lato-lato：印尼 game lato lato 20/月、lato lato online 10/月，已有网页版；不能凭 2023 年玩具潮认定当前热点。
- Balap karung：已有 Own Games 网页和 Mojiken 的 HTML5 游戏；独立日季节题材需在对应周期前验证，当前 10 月不优先。balap kelereng 最近三月 590→1,900→170 也不能当持续增长。
- 菲律宾 color game：135,000/月、KD 17，但公开竞品大量为现金博彩产品；流量意图不匹配一个普通免费 Three.js 休闲站。越南骰子类同样需先拆解意图，不用大词热度决定开发。

## 决策

若目标是尽快上线一个可承接明确搜索意图的页面：选菲律宾英语 Duck Race Name Picker，预算 3–5 天，先验证是否能让用户替换原工具。

若必须强调操控型小游戏且愿意追加本地语言与手感调试：备选虚拟抓娃娃。若只接受中英文且要控制工期，先做鸭子工具最符合当前约束。

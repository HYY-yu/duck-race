# Duck Circuit / 鸭子障碍赛

> 归档参考版本（2026-10-22）：本目录保留旧项目及迁移前的未提交修改。主项目现为仓库根目录的 Duck Rush。下文为历史说明，其中根目录命令、绝对路径及子包对比入口描述属于迁移前状态。当前在仓库根目录使用 `npm run dev:legacy` 启动本版（5181），或进入本目录运行 `npm ci`、`npm run dev`、`npm test`、`npm run build`。

独立 Three.js + TypeScript 水道竞速原型。5 只鸭子从山顶起跑池出发，沿连续下降的山谷河网漂流，经过两处分流汇流、三段叠瀑、大摆锤、深窄急流与高低闸杆。鸭子没有自主推进能力；共享水流、弯道线路和实际碰撞决定名次，无预定赢家或隐藏追赶加速。

当前地图「叠瀑山谷 / Cascade Highlands」全长约 359 m，整体落差约 63 m。默认展示全景，开始比赛后切入 3D 俯视跟随镜头，可随时切换关注的鸭子；分流与陡降前会调整构图，呈现不同水路、前后落差和汇流争先。暂不包含声音。鸭子保留独立角惯性，可横漂和倒漂；身体部分入水，随水面升沉、俯仰及横摇，转弯时不会强制把头对准行进方向。

[赛道全景](docs/highlands-overview.png) · [水面跟随视角](docs/water-follow.png) · [叠瀑水体](docs/water-cascade.png) · [设计与验收](docs/PLAN.md)

水体复用 Three.js Water2 的 MIT 双相流动法线算法，配合两张原创 256 × 256 法线纹理与物理材质，表现随河道弯曲和坡度变化的波纹、折射、深浅吸收及反光。环境反射来自一次性采集的实际山谷与程序天空，未包含动态鸭子倒影；水底另有碎石和程序焦散，陡降处叠加白水、喷溅与柔化尾迹。小幅水面起伏仅用于视觉，不改变竞速物理。

## 第一处瀑布样板 / Headwater prototype

点击画面右下「瀑布近景 / Waterfall close-up」，或打开 `http://127.0.0.1:5183/?waterfall`。该角度可以直接开始比赛，约 10–14 秒比赛时间可看到五只鸭子离开崖口、受重力下落、入水飞溅及短暂下沉回浮；返回赛道按钮恢复常规镜头。

`sim-0.5.0` 修复分合流处的水面顶点、法线、距岸衰减和流速属性不连续，河岸与地形使用同一条外沿。第一处从缓坡改为 9 m 岩壁后的自由水帘，下方保留实际可漂浮的深潭。水帘、岩石和泡沫为项目实现；飞溅/水雾复用 three.quarks，纹理仍为原创程序生成。后两段保留急流形态。见 [专项验收](docs/PLAN.md) 和 [瀑布近景](docs/headwater-prototype.png)。

## 启动

需要 Node.js 22.18+（测试直接运行 TypeScript）或 Node.js 24 LTS，以及 npm。

```sh
npm ci
npm run dev
```

默认打开 http://127.0.0.1:5181 。当前在 5182 端口体验时，可显式启动：

```sh
npm run dev -- --port 5182
```

`npm run build` 执行严格类型检查与生产构建；`npm test` 验证水流与碰撞约定、倒计时和暂停生命周期、固定步进回放、分流/汇流、温和斥力、有限样本完赛，以及水体和河床的几何、材质与资源释放约定。本轮自动测试 54/54 通过；浏览器检查与构建记录见验收文档。

## 操作

- 展开「参赛设置」，输入最多 5 行名字；不足时补默认名字。名字和配色不影响运动参数。
- 点击「开始比赛」，经过 3 秒倒计时与五盏起跑灯后放行。倒计时和比赛都能暂停／继续；切到后台会自动暂停，返回后手动继续。
- 点击排行榜中的选手、画面中的鸭子，或按 `1`–`5` 切换跟随目标；左右方向键和镜头栏箭头切换上一只／下一只。
- 「全景赛道／跟随鸭子」切换整体布局与俯视跟随镜头。小地图显示赛道位置，右侧显示所跟随鸭子的河段、所在支路、局部流速、剩余落差与本场超越次数。
- 重置保留种子并回到待发令状态；完赛后可「再赛一场」。种子仅打乱身份与起跑槽位的对应关系，地图及障碍相位固定。
- EN／中文切换界面语言。在地址后加 `?debug` 开启镜头、限频碰撞与帧率采样日志；默认记录赛事节点与异常，不写入参赛姓名。

## 原型边界

这是带高度的 3D 水道展示，使用简化共享流场和水道坐标碰撞，不是完整自由表面流体或六自由度刚体求解。界面按米制显示场景尺度，流速是用于游戏的近似值。深窄道通过缩小过水截面并增加坡降来加速，并非水越深就必然越快。

水体采用物理材质的折射和吸收近似，不是体积流体求解。静态环境反射没有局部视差，也不是屏幕空间反射（SSR）。透射增加一次半分辨率的不透明场景颜色绘制，厚度来自预计算的河道深度；着色器未读取屏幕深度来排除前景，画面边缘和离屏内容存在限制。调试统计覆盖阴影、透射和主画面各阶段，不能只按主画面的 draw calls 评估开销。

使用原创程序几何鸭；Three.js 已升级到 0.186.1，并使用 three.quarks 0.17.1（MIT）驱动第一处瀑布的飞溅与水雾。没有后端、账户或外部媒体服务。名单只保留在当前页面内存中，不上传、不自动保存。本项目尚未公开部署。

起跑位置、路径和障碍相位可能产生胜率偏差；同运行时可复现不等于抽签公平，跨设备逐帧一致性未验收。180 秒仍未全员完赛会暂停并提示重置，不会暗中传送鸭子救援。移动真机性能仍待验证。


## Duck Rush 独立对比子包

新增 `packages/duck-rush`，保留原项目的运行入口和依赖。两者分别运行在不同端口：

- 原版：`npm run dev` → http://127.0.0.1:5181
- Duck Rush：`npm run dev:rush` → http://127.0.0.1:5183
- 子包安装：`npm --prefix packages/duck-rush ci`
- 子包检查：`npm run test:rush`、`npm run build:rush`

子包包含卡通山谷竞速场景、参考原版水体方法适配的物理水材质、独立瀑布水帘、鸭子弹道下落及碰撞反馈。详见 [子包说明](packages/duck-rush/README.md) 和 [水体/物理实现](packages/duck-rush/docs/WATER-PHYSICS.md)。

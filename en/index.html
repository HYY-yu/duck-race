Race rules

No preset winner. No hidden automatic outcome.

Transparent automatic mode

Names are securely randomized onto duck IDs and never influence the physics. There is no preset winner or name-based boost; the simulated course produces the finishing order.

Automatic-only public race

The public version accepts no player input that can steer a duck or change the outcome. Following a duck changes only the camera.

What fairness means here

Automatic mode separates secure name assignment from race physics and exposes the real full ranking. It is transparent casual selection, not a certified draw or proof of identical physical odds on every course.

Names stay local by default

Duck Rush has no account, remote name database, built-in name-upload API, or configured analytics destination. Names and the last 10 results stay in this browser, and the public build does not request microphone access.

Help

Duck race name picker FAQ

How many names can I add?

Each race supports 2–12 unique names. This version is not designed for whole-school or thousand-person draws.

Is the Duck Rush result fair?

The public version is automatic-only. The browser’s secure random source assigns names to ducks, there is no preset winner or name-based physics, and the simulated course determines the actual finish. Duck Rush is not an independently certified draw.

Are participant names uploaded?

Not by Duck Rush’s built-in code. There is no account, name-upload API, remote name database, or configured analytics destination; names and recent history stay in this browser by default.

Is the winner selected before the animation?

No. Names are randomly assigned to physical duck IDs, then the current river simulation produces the actual finishing order.

Why do ducks overtake each other?

The course has changing flow, bends, narrow sections, waterfalls, obstacles, and duck collisions. Those simulated interactions can change positions throughout the race.

Can I share the same course?

The track and seed URL parameters reproduce course choices and generated mountain geometry. They are page state, not separate indexable pages.

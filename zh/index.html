比赛规则

无预设赢家。自动结果不暗箱决定。

透明自动模式

姓名通过安全随机源分配给小鸭，且不参与物理计算。没有预设赢家或姓名专属加速；赛道仿真产生最终排名。

公开版本仅自动竞速

公开版本不接受任何能够控制小鸭或改变结果的玩家输入。跟随小鸭只会切换观看镜头。

这里的公平含义

自动模式把安全随机分配与比赛物理分开，并公开完整真实排名。它是规则透明的休闲抽签，不是认证抽签，也不证明每条赛道上的物理编号胜率完全相同。

名单默认只在本地

Duck Rush 没有账号、远程名单数据库、内置名单上传 API 或已配置的远程分析目的地。姓名与最近 10 场结果保存在当前浏览器，公开版本不会请求麦克风权限。

帮助

常见问题

一场比赛支持多少人？

每轮支持 2–12 个不重复名字。本版本不适合全校、千人活动或大型抽奖。

Duck Rush 的结果公平吗？

公开版本只有自动竞速。浏览器安全随机源分配姓名，没有预设赢家或基于姓名的物理差异，再由赛道仿真产生实际冲线顺序。Duck Rush 不是经过独立认证的抽签系统。

参与者姓名会上传吗？

Duck Rush 的内置代码不会上传姓名：项目没有账号、名单上传 API、远程名单数据库或已配置的分析目的地，姓名与历史默认只在当前浏览器。

赢家会在动画开始前预先选好吗？

不会。名字先随机分配到小鸭的物理编号，再由当前河道仿真产生真实冲线顺序。

为什么比赛中会发生超越？

河道包含流速变化、弯道、窄道、瀑布和障碍，小鸭之间也会碰撞；这些交互会不断改变相对位置。

可以分享同一条赛道吗？

URL 中的 track 与 seed 参数可复现赛道选择和雪山地形。它们只是页面状态，不是独立收录页面。

数据边界

隐私说明

参与者姓名和完赛历史默认只在当前浏览器。Duck Rush 不内置账号系统、名单上传 API、远程名单数据库；配置 PostHog 后会发送汇总使用统计；公开的纯自动构建不会请求麦克风权限。

默认本地：参与者姓名与比赛历史

设置与比赛期间，姓名在浏览器内存中处理。当前代码不内置账号、名单上传接口或远程名单数据库。比赛完成后，Duck Rush 使用 localStorage 保存最近 10 场记录，可能包含姓名、分配颜色、冲线顺序与时间、日期、赛道、赛道种子、比赛种子和抽签编号。

可以通过“抽签记录 → 清除本机记录”删除完赛历史；在浏览器设置中清除本站数据也会删除记录。尚未完成的名单配置不会作为比赛历史保存。

不使用麦克风或结果控制

公开版本只有自动竞速，不渲染麦克风控制，不请求麦克风权限，也不注册能够控制小鸭的键盘输入。全局与跟随功能只改变观看镜头。

剪贴板、声音与模型资源

只有点击“复制结果”时，Duck Rush 才会尝试把冲线顺序写入剪贴板。声音由应用生成且默认关闭。随项目发布的 3D 模型会在可玩场景启动后从同一站点加载，不依赖第三方字体或模型 CDN。

诊断与观测

当前应用会按 Debug、Info、Warn、Error 级别向浏览器控制台记录资源加载、比赛状态、可恢复的存储问题与异常。轻量观测适配层记录页面语言、赛道、游戏加载、汇总参与人数、完赛耗时、Web Vitals 和资源失败；设计上不包含真实姓名、复制结果或未经筛选的完整 URL/查询参数。

部署配置 PostHog 项目 Key 和接收地址后，上述事件将发送至 PostHog。自动点击和表单采集、会话回放、用户画像与自动错误采集均关闭。属性白名单移除完整 URL、查询参数、来源地址、姓名和语音文本。分析使用内存中的临时匿名标识，不写入持久化分析 Cookie，刷新后生成新标识；尊重浏览器 Do Not Track，并关闭 IP 地理定位。接收服务仍可在网络请求中看到 IP 地址。详情见 PostHog 隐私政策。未配置的构建不会发送分析事件。

生产托管与外部服务

Duck Rush 已发布在 duckracepicker.com，使用 Cloudflare Workers Static Assets 托管。Cloudflare 同时提供权威 DNS、TLS、代理、CDN 分发和相关安全服务。Cloudflare 可能按照其隐私政策处理 IP 地址、请求头、网络诊断以及安全或交付日志；Duck Rush 无法控制 Cloudflare 的保留周期。

PostHog 是上述可选产品分析目的地。截至 2026 年 10 月 24 日，Google Search Console 尚未接入。PostHog 数据保留周期由站点运营方的项目设置控制，本页不承诺固定保留期限。运营主体与公开联系渠道仍待公布。

URL 参数

track 与 seed 用于描述赛道状态。Duck Rush 不会把参与者姓名写入 URL。不要手动把个人信息添加到 URL，因为它可能出现在浏览器历史、服务器日志和分享链接中。

# TRELLIS.2 参考图配色版本

2026-10-22：用户选择 TRELLIS.2 造型，要求配色接近参考图。本地修改模型贴图和材质，没有重新生成、付费或接入游戏；原件保留。

- 身体主色：sRGB `#FED733`，参考图 `(650,260)` 周围 33×33 像素 RGB 中位数。
- 嘴主色：sRGB `#F46A14`，参考图 `(380,460)` 同样取样。
- 参考图有光照和明暗，不存在整只鸭子通用的一个颜色。上述是局部取样基色，保留少量贴图明暗；实际渲染颜色还会受灯光、材质影响，不承诺每个屏幕像素一致。
- 保留眼部纹理及暗部，未消除原生成眼睛的杂点。
- 身体/嘴按原贴图色域进行确定性映射；几何、索引和 UV 字节保持一致，10,000 三角面。
- 设置非金属橡胶材质：metallic 0、roughness 0.65，移除不再使用的金属/粗糙度贴图。
- `duck-reference-colors.glb`：311,880 字节（304.57 KiB），一张 1024×1024 颜色贴图，无骨骼动画。

复现：`node scripts/recolor-trellis-duck.mjs`，使用 Node 内置模块，无新增依赖或在线生成。完整取样和统计见 `palette.json`。

预览：`http://127.0.0.1:5183/assets/generated/duck-base-trellis-color-v1/preview.html`。参考图、TRELLIS.2 原版、改色版使用相同灯光与相机。原件缺法线，预览计算平滑法线，不改变 GLB 原件。

检查：原版与改色版的所有几何/UV accessor 字节相同；GLB 总长度及 bufferView 边界通过；Three.js GLTFLoader 加载与斜前方、背面、侧面查看通过。尚未做游戏内或移动设备验收。

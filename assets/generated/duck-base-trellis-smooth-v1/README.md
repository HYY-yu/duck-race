## 方法与限制

在 1e-6 坐标精度下，为位置重合的 UV 接缝顶点建立共同邻接，得到 5,002 个逻辑顶点；不实际焊接 UV。使用面积加权法线并将一致法线写回 UV 分裂顶点。

Taubin lambda=0.35、mu=-0.36，共 12 轮。大于 60° 的 153 条锐边附近减弱移动，1 条边界/异常边锁定，位移上限约为模型最大边长的 1.4%。这属于按几何特征保护，不是手工语义分区；嘴和翅膀仍有轻微圆化。检测到一个三角面相对原始朝向转动超过 90°，已恢复涉及的 3 个逻辑顶点；最终检查没有此类翻面。该检查不等于完整自相交检测。

最终 RMS 顶点位移约 0.00404，包围盒尺寸变化很小。仅修复法线已消除大部分碎面明暗；Taubin 进一步减轻头、身体及翅膀局部凹凸。原有纹理杂点、接缝细线不会由几何平滑自动清除。

## 复现与验证

`node scripts/smooth-trellis-duck.mjs`。Node 内置模块，无新增依赖。它仅处理当前已检查的单网格、非交错 GLB 样品，不是通用 glTF 转换器。参数、位移和尺寸在 `stats.json`。

GLB 长度、bufferView 范围、位置/法线有限性、单位法线、原索引/UV/贴图一致性以及无大于 90° 面朝向反转检查通过，见 `validation.json`。Three.js 实际加载、斜前方/侧面/背面外观检查通过。尚未做完整 Khronos 验证、自相交分析或移动设备/游戏内验收。
